## 🚀 Getting Started
- Prerequisites: Python 3.11 or higher, pip package manager.

### Installation

```bash
git clone <your-repository-url>
cd rag-technical-app
```

### Set up the Virtual Environment:

```bash
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
```

### Install Dependencies:

```bash
pip install -r requirements.txt
```

### Launch the Tool:

```bash
python app.py
```

---
## 🔬 Troubleshooting

- **Virtual Environment Missing?** Ensure you activated your `venv` instance before calling `python app.py`.
- **Configuration Overrides?** Add custom block components inside `pyproject.toml` to instantly update parameters.
